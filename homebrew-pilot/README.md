# Homebrew Tap for Medal Social

Install Pilot (CLI) via Homebrew:

```bash
brew install Medal-Social/pilot/pilot
```

Install Medal Social Desktop via Homebrew:

```bash
brew install --cask Medal-Social/pilot/medal-social
```

Or add the tap first:

```bash
brew tap Medal-Social/pilot
brew install pilot
brew install --cask medal-social
```

## About

- **Pilot** — Medal Social's AI-powered CLI platform: [github.com/Medal-Social/Pilot](https://github.com/Medal-Social/Pilot).
- **Medal Social Desktop** — the Medal Social desktop app: [github.com/Medal-Social/Desktop](https://github.com/Medal-Social/Desktop). Updates between brew runs are handled by the in-app OTA updater.
